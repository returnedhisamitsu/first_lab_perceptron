# Perceptron

Учебный проект: реализация однослойного перцептрона для бинарной классификации на Python.

## Возможности

- Обучение перцептрона методом коррекции весов.
- Генерация синтетических линейно разделимых данных.
- Настройка learning rate и количества эпох.
- Воспроизводимость данных через seed.
- Визуализация датасета и границы решения.
- График ошибок по эпохам.
- Проверка модели на реальном датасете Iris.

## Установка

```bash
git clone <https://github.com/returnedhisamitsu/first_lab_perceptron>
cd perceptron
uv sync
```

## Запуск

```bash
uv run python -m perceptron --samples 200 --lr 0.1 --epochs 50
```

| Аргумент | Описание | По умолчанию |
|---|---|---|
| `--samples` | Количество образцов | 200 |
| `--lr` | Скорость обучения | 0.1 |
| `--epochs` | Количество эпох | 50 |

Посмотреть доступные аргументы:

```bash
uv run python -m perceptron --help
```
